# Finger Stone 🧤

손동작으로 PC를 제어하는 **웨어러블 건틀렛**입니다. 별도의 물리 입력장치 없이 손가락 굽힘만으로 발표 슬라이드를 넘기고, 손목 심박 센서로 발표자의 긴장 상태를 모니터링합니다.

> 가천대학교 기초공학설계 (2026-2학기) · 팀 **A+vengers** · 2026.09.01 ~ 2026.12.08

## 주요 기능

- **제스처 입력**: Flex Sensor 5개(손가락 전부)의 굽힘 값으로 제스처를 판정하고 Bluetooth HID로 PC를 제어합니다. (다음/이전 슬라이드, 클릭, 스크롤)
- **심박 모니터링**: 손목에 고정한 심박 센서로 실시간 심박수를 측정합니다.
- **모듈식 구조**: EMG 모듈(MyoWare 2.0) 없이도 동작하는 소프트웨어 구조를 목표로 합니다.

이전 버전(ver.1)의 밴드형 구조를 건틀렛 형태로 발전시키고, 부품을 내부에 통합하는 것이 목표입니다.

## 시스템 구조

```
[Flex x5] ──ADC1──┐
[MyoWare 2.0] ─ADC1─┼─> ESP32 ──BLE HID──> PC (슬라이드/클릭/스크롤)
[SEN0203 심박] ─GPIO(IRQ)─┘
```

1. 부팅 시 캘리브레이션 (손 펴기/주먹 쥐기의 채널별 ADC 최소/최대 기록)
2. 0~1 정규화와 필터링 (이동 평균/중앙값)
3. 규칙 기반 제스처 판정 (손가락 조합, 임계값, 히스테리시스, 디바운스)
4. BLE HID 매핑

MVP 이후에는 동작 로그를 이용해 작은 분류기로 임계값을 보정할 계획입니다.

## 하드웨어

| 부품 | 수량 |
|---|---|
| ESP32-DevKitC (Wi-Fi) | 1 |
| Flex Sensor | 5 |
| MyoWare 2.0 (EMG) | 1 |
| Gravity Heart Rate Monitor SEN0203 | 1 |
| 저항 47kΩ / 1kΩ | 5 / 2 |
| 커패시터 100nF / 100µF | 7 / 1 |

- 전원: 보조배터리를 USB 케이블로 ESP32 보드에 연결합니다. 센서는 모두 **3V3**로 구동합니다. (5V 구동 금지)
- 상세 부품 목록과 회로 설명은 [docs/design-notes.md](docs/design-notes.md)를 참고하세요.

### 핀맵

| 센서 | GPIO |
|---|---|
| Flex 엄지 / 검지 / 중지 / 약지 / 새끼 | 36 / 39 / 34 / 35 / 32 |
| MyoWare 2.0 | 33 |
| SEN0203 | 27 |

아날로그 센서는 Wi-Fi 영향이 없는 ADC1 핀에 배치했습니다.
